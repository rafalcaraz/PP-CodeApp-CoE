============================================================
02 - RESOURCE TYPES
============================================================

The inventory exposes 10 resource types. Every paste must
target one or more of these in a "where type ==" (or
"where type in~") clause. Strings are CASE-SENSITIVE.


------------------------------------------------------------
QUICK LOOKUP
------------------------------------------------------------

Friendly name             Type value                                       When to query it
-----------------------   ----------------------------------------------   -----------------------------------------------------------
Canvas app                microsoft.powerapps/canvasapps                   User-built drag-and-drop apps. Richest connector metadata.
Model-driven app          microsoft.powerapps/modeldrivenapps              Dataverse-backed structured apps (Customer Service Hub, ...). Sparse -- no powerPlatformConnectors.
Code app                  microsoft.powerapps/codeapps                     Pro-dev "bring-your-own-code" apps (React/TS/Vite). Sparsest type.
App-builder app           microsoft.powerapps/apps                         Different app surface. Uses properties.connectors (NOT powerPlatformConnectors). connectorId is an ARM path.
Cloud flow                microsoft.powerautomate/cloudflows               Power Automate flows. Has status, flowTriggerType, trigger.
Agent flow                microsoft.powerautomate/agentflows               Same shape as cloud flows.
Workflow agent flow       microsoft.powerautomate/m365agentflows           Same shape as cloud flows.
Copilot Studio agent      microsoft.copilotstudio/agents                   Richest schema. Has model, orchestration, channels, lastPublishedAt, ...
Environment               microsoft.powerplatform/environments             Power Platform environments. Owns environmentType and isManaged.
Environment group         microsoft.powerplatform/environmentgroups        Groups of environments for governance. Sparse.


------------------------------------------------------------
"APPS" USUALLY MEANS ALL FOUR APP TYPES
------------------------------------------------------------

When the user says "apps" without qualification, target all
FOUR app resource types via in~:

  {
    "$type": "where",
    "FieldName": "type",
    "Operator": "in~",
    "Values": [
      "'microsoft.powerapps/canvasapps'",
      "'microsoft.powerapps/modeldrivenapps'",
      "'microsoft.powerapps/codeapps'",
      "'microsoft.powerapps/apps'"
    ]
  }

If they specify a kind ("canvas apps", "code apps"), use only
that one with ==. "Apps and flows" -> add the flow types too.


------------------------------------------------------------
"FLOWS" USUALLY MEANS ALL THREE FLOW TYPES
------------------------------------------------------------

When the user says "flows" without qualification:

  {
    "$type": "where",
    "FieldName": "type",
    "Operator": "in~",
    "Values": [
      "'microsoft.powerautomate/cloudflows'",
      "'microsoft.powerautomate/agentflows'",
      "'microsoft.powerautomate/m365agentflows'"
    ]
  }

If they say specifically "cloud flows" -> only cloudflows.
"Agent flows" -> only agentflows (and ASK if they meant
Copilot Studio AGENTS instead -- different concept).


------------------------------------------------------------
COMMON ENVELOPE (every type has these)
------------------------------------------------------------

These top-level fields exist on every record and you can
filter on them directly (no properties. prefix):

Field        Type            Notes
---------    ------------    --------------------------------------------------
id           string          Full ARM path. Rarely useful for filtering.
name         string (GUID)   The resource GUID -- same as the trailing segment of id.
type         string          One of the 10 strings above. Already set by your resourceTypes clause.
tenantId     string (GUID)   Almost always the same in a single tenant.
location     string          Azure region, lower-case (e.g. 'unitedstates', 'westus').


------------------------------------------------------------
RESOURCE-TYPE-SPECIFIC EXTRAS (high-level)
------------------------------------------------------------

Per-resource-type details live in 03-fields-reference.
Headlines:

CANVAS APPS:
  powerPlatformConnectors[], lastLaunchedTime, sharedUsersCount,
  sharedGroupsCount, appType, isFeaturedApp, bypassConsent.

MODEL-DRIVEN APPS:
  logicalName, appModuleId.

CODE APPS:
  subType (e.g. 'byocApp').

APP-BUILDER APPS:
  connectors[] (ARM-path connector IDs), subType: 'appBuilderApp'.

CLOUD / AGENT / M365 AGENT FLOWS:
  status ('Activated', 'Suspended', 'Stopped', 'Started',
  'NotStarted'), flowTriggerType ('Instant', 'Automated',
  'Recurrence', 'Manual'), trigger object (operationId,
  connectorId, ...), workflowEntityId, powerPlatformConnectors[].

COPILOT STUDIO AGENTS:
  model (e.g. 'Claude Sonnet 4.5', 'GPT-4o'), orchestration
  ('Generative', ...), channels[], lastPublishedAt, schemaName,
  entraAppId, instructionsCharactersCount,
  isWebSearchEnabledForKnowledge, sharedWithEditors,
  sharedWithViewers, capabilitiesCounts.

ENVIRONMENTS:
  environmentType ('Production', 'Default', 'Sandbox', 'Trial',
  'Developer', 'Dataverse for Teams'), isManaged,
  environmentGroup, environmentGroupId.

ENVIRONMENT GROUPS:
  displayName, description, createdAt, createdBy.
